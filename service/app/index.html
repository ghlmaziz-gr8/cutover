                        Database structure

                        Upload the .json file made by the read-only script (access_metadata.py) to add the table and field names of a database. The file holds names, types, sizes, nullability and row counts only. It holds no row values.

                        Run deep data assessment

                        This reads the code again and builds the business, systems, data and workflow documents. It includes the database structure above when one is saved.

                        The database structure appears under Data structure on the report when this run finishes.
